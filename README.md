# WiFiCraft - texturepacki

Każdy folder to osobny texturepack serwera WiFiCraft (gotowy folder paczki z `pack.mcmeta`):

| Folder | Paczka |
|---|---|
| `boxpvp/` | BoxPvP WIFICRAFT.PL |

Aktualizacja: uruchom `wyslij_paczki.bat` - kopiuje najnowsze wersje paczek z gry do swoich folderów i wysyła je tutaj.
Nową paczkę dodaje się jedną linijką `call :paczka "folder" "ścieżka"` w tym pliku.

Prawa autorskie: patrz `copyright.txt` w każdej paczce.
